# Screenshots

Save README screenshots here with these names:

| File | What to capture |
|---|---|
| `board-desktop.png` | Board at about 1280px wide, no filters |
| `board-phone.png` | Board at 375px wide, showing the column switcher |
| `report-form-phone.png` | Report form at 375px after pressing "Report issue" empty, so the inline errors show |
| `issue-detail.png` | A detail panel with a few history entries, e.g. issue #24 (the reopened floor drain) |

Tip: in Chrome DevTools, open the device toolbar (Ctrl+Shift+M), pick a width, then use the ⋮ menu → "Capture screenshot".
Run `npm run db:seed` first so the ages look fresh.
